## 1. Что плохо сейчас (по результатам прогулки 29 апреля 2026)

Прогулка по `https://ai.scqr.ru/` и `/blog/` показала три проблемы:

1. **Стилевая каша.** На странице архива одновременно висят:
   - тёмные фоторендеры с деталями железа (AlphaFold 4, «Корпоративные агенты», «Большие лаборатории продают режим доступа», «Протоколы для агентов»),
   - лиловые редакционные карточки в нашем стиле (Anthropic AWS, GPT-5.4-Cyber, гигаватты),
   - белые квадраты с буквами вместо обложек (три свежие статьи: data-fabric, marketplace-agentov, skorost-vypuska-modeley).
2. **Кадрирование ломает смысл.** Карточки архива у нас 4:3, многие обложки сделаны под 16:9 без запаса по центру: у «Agent Cloud делает агентов больше похожими на облачный сервис» в карточке видно «АТЫ БАЛАНСЕ» — обрезанная подпись, а не смысл.
3. **Нет единого визуального языка между статьями.** Главная страница и архив читаются как четыре разных сайта.

Цель пакета — закрыть три эти болезни одним заходом ChatGPT-Pro:
- три статьи получают свои обложки,
- 7–10 архетипических заготовок попадают в общий пул для будущих статей,
- маскот переходит в полноценный набор поз на прозрачном фоне.

```

Шрифт текста на обложке:
- Inter, system-ui sans-serif
- Заголовок: weight 700, тёмный navy #17142E
- Подзаголовок: weight 500, муть-лиловый #5C5685

Запрещено:
- Фотореализм
- 3D-рендеринг кубов / роботов / деталей железа со студийным светом
- Логотипы реальных компаний (NVIDIA, OpenAI, Anthropic, AWS, Google)
- Стоковые иллюстрации с гладкими градиентами
- Маскот в обложках статей (он живёт в hero/footer/CTA)
- Слова «AI», «GPT», «Future», «Innovation» большими буквами

Обязательно:
- Один сильный смысловой объект — метафора тезиса статьи
- Тонкий dot grid фоном (низкая прозрачность)
- Маленький логотип SCQR в правом верхнем углу: фиолетовый круг с одной лаймовой точкой, 60×60 px area

- Заголовок и подзаголовок в верхнем левом углу, помещаются в 35% ширины
- Тонкая лаймовая линия по нижней кромке (5% высоты) — фирменная подпись

Размер: 1536×1024 (3:2). PNG, без альфы.
Цветовое пространство: sRGB.
```

## 4. Промт для маскота на прозрачном фоне

> Отдельный заход в ChatGPT. Маскот — наш лицо-узнаваемость, у него отдельная анатомия, не путать с обложками.

### 4.1. Преамбула

```
Сгенерируй пачку из 6 поз маскота SCQR. Каждая — отдельный PNG 1024×1024 с ПОЛНОСТЬЮ ПРОЗРАЧНЫМ фоном (alpha-канал, без шахматной заливки, без белого подложного цвета, без градиента).

Параметры genertion API: background = "transparent", output_format = "png".

Анатомия маскота (одна для всех поз):
- Гладкий округлый персонаж в виде дружелюбного аналитика-исследователя.
- Стиль: плоский вектор с тонким лиловым контуром (#A99BEA), белым телом, фиолетовыми акцентами #7C5CFF.
- ОБЯЗАТЕЛЬНЫЕ КРАСНЫЕ ОЧКИ — крупные, прямоугольные с закруглёнными углами, цвет ярко-красный #F23B3B. Очки сидят на лице, в линзах фиолетовые зрачки с лаймовой точкой по центру.

- Тело и конечности — простые геометрические формы, тёмно-navy #17142E для штанов и обуви.

ЗАПРЕЩЕНО:
```

## 5. Что я сделаю после получения файлов

Когда ChatGPT отдаст файлы по указанным путям:

1. **Запустится автоматический pickup** через `/api/article-codex-import/<slug>` — для трёх свежих статей (data-fabric, marketplace-agentov, skorost-vypuska-modeley) обложки автоматически подвяжутся к статьям, в frontmatter пропишется `heroImage`, в sidecar — `ogUrl`.
2. **Шаблоны архетипов** в `site/public/editorial/templates/` будут использоваться как fallback для будущих статей: при создании новой статьи я буду подбирать ближайший архетип, копировать в нужный путь, при необходимости накладывать новый текст.
3. **Маскот на прозрачном фоне** заменит существующие файлы в `site/public/editorial/2026-refresh/mascot/`. Ссылки на маскота в Header/Footer/HomeHero/HomeNewsletterBanner будут продолжать работать без изменений (имена файлов сохранены).

- Для каждой подберу один из архетипов выше (стек / два игрока / периметр / таймлайн)
- ChatGPT сделает второй пакет из 12 обложек
- Подвяжу их через тот же auto-pickup механизм
