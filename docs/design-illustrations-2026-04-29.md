Зайди в `/editor`, выбери статью, нажми **«🤝 Через Codex»** — серверный poller увидит файл и автоматически подвяжет обложку (frontmatter heroImage + sidecar ogUrl).

2. **Последние 6** (template-*) лежат в `site/public/editorial/templates/`. Это резерв для статей, которые я буду писать по сюжетам из дайджеста. Когда возьму один из них — скопирую файл в нужный путь под slug, заголовки переменю при необходимости через текстовый патч.

3. Если какая-то обложка после генерации не попадает в стиль — попроси Codex переделать её с другим seed, ничего больше не двигая.
