# Семьи визуальных стилей SCQR

> Четыре цветовые семьи для обложек статей. Все построены вокруг одного маскота, одной композиции и одной типографики — различаются только палитрой и настроением. Каждая семья закреплена за определённым типом сюжетов.

---

## Что общее во всех четырёх семьях

- **Маскот.** Тот же 3D-белый персонаж с **красными прямоугольными очками** (`#F23B3B`). Очки — единственная константа, не меняется ни в одной семье. Они и есть фирменная подпись SCQR.
- **Логотип.** В правом верхнем углу — фиолетовый круг-петля с одной лаймовой точкой (`#7C5CFF` + `#A3E635`), 60×60 px area. Всегда. Это якорь, по которому глаз узнаёт SCQR независимо от палитры обложки.
- **Композиция.** Главный смысловой объект в центральных 60% по горизонтали; заголовок и подзаголовок в верхнем-левом углу; тонкая горизонтальная сигнальная линия по нижней кромке (5% высоты, цвет — основной акцент семьи).
- **Дисциплина.** 3D-фоторендер, soft studio lighting, depth-of-field. Никакого фотореализма уровня NVIDIA-промо, никаких логотипов реальных компаний, никаких больших надписей AI / GPT / Future.
- **Размер.** 1536×1024 PNG sRGB.
- **Шрифт.** Inter / system-ui sans-serif. Заголовок weight 700 тёмный (цвет «тяжёлого» элемента семьи). Подзаголовок weight 500 муть-лиловый или близкий по семье.

## Семья A · «Сигнальный лиловый» — Lilac × Lime

> Default. Ставится по умолчанию, если в задании не указан другой стиль.

**Палитра**

| Слой | HEX | Назначение |
|---|---|---|
| Фон-светлый | `#F1ECFF` | основной градиент |
| Фон-тёмный | `#E9E2FF` | градиент к нижней части |
| Тяжёлое | `#17142E` | navy для серверов, плит, стеллажей |
| Основной акцент | `#A3E635` | лайм, сигнальные линии и контрольные точки |
| Доп. акцент | `#7C5CFF` | фиолетовая подсветка, кнопки |
| Тёплый край | `#FFF8E8` | по необходимости, лёгкая бумажная нота |

**Настроение.** Электрический, оптимистичный, сигнальный. Свет «вот сейчас что-то произошло на рынке».

**Когда использовать.**
- Структурные сдвиги рынка (агенты, портфели моделей, инфраструктурная гонка)
- Новые продукты и архитектуры
- Карты вендоров, портфельные истории
- Общая аналитика без специфической эмоциональной окраски

**Примеры.** «Маркетплейс агентов уже работает», «Двенадцать месяцев фронтира», «Слой данных стал фундаментом», «Корпоративные агенты выходят из пилота».

**Настроение.** Архивный, бюрократический, документальный. Свет позднего вечера, перегородки кабинета.

**Когда использовать.**
- Регуляторика, госконтракты, политические решения
- Финансовые сделки на много миллиардов, IPO, M&A
- Исторические параллели и ретроспективы
- Российский рынок, госаппарат, советская/постсоветская аналитика
- «Деньги, контракты, бумаги, печати»

**Примеры будущих обложек.** «Pentagon получил Google после отказа Anthropic», «OpenAI ушла к Amazon на 50 млрд», «Регулирование переходит в режим допуска», «AI Diffusion Rule в США».

**Особенность.** Маскот в красных очках на тёплом фоне выглядит как ретро-комик — это правильно для исторического регистра.

**Настроение.** Тревога, шок, развилка, ограничение. Свет пожарного предупреждения, но не паника — спокойный сигнал «что-то поменялось».

**Когда использовать.**
- Регуляторные блокировки и баны (Wuhan robotaxi freeze, AI Diffusion Rule restrictions)
- Кризисы рынка, обвалы, отзывы продуктов
- Развилки с явным «нет» — отказы (Anthropic от Pentagon)
- Геополитические шоки и санкции
- Юридические иски и судебные разбирательства

**Примеры будущих обложек.** «Робомобили в Китае встали», «Sam Altman face of evil — лица за иски OpenAI», «Anthropic отказался работать с Pentagon», «Ормуз снова стал осью мировой экономики».

**Особенность.** Navy остаётся как тяжёлый якорь — это связь с семьёй A, чтобы фон не уходил в слишком другую эстетику. Красные очки маскота на коралловом плавятся в одну тёплую массу — это даёт «солидарность» персонажа с настроением.

## Как Codex выбирает семью

В каждом задании в frontmatter указывается поле `style`:

```yaml
---
type: cover
slug: ...
style: lilac-lime    # | amber-indigo | teal-cyan | coral-navy
target_path: ...
---
```

Если поле отсутствует, по умолчанию `lilac-lime` (семья A).

В теле задания дополнительно идёт текстовый блок «**Стиль семьи**: [название]» с палитрой — это страховка на случай, если Codex пропустит frontmatter.

## Правило баланса на сайте

Чтобы лента архива и главная не уходили в один цвет:

- **Семья A (lilac/lime)** — большинство (≈55–60% обложек). Это «дыхание сайта».
- **Семья B (amber/indigo)** — ~15%. Подсвечивает регуляторно-исторические сюжеты.
- **Семья C (teal/cyan)** — ~15%. Технические/методологические материалы.
- **Семья D (coral/navy)** — ~10%. Только настоящие шоки, чтобы цвет не девальвировался.

Если приходит сюжет на стыке двух семей — выбирай ту, чьё настроение ближе к редакционному акценту материала. Например, «Регуляторный шок в Китае» — это **D** (шок) важнее **B** (регуляторика).
