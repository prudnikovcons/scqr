# Обложка: «Где встречаются память и логика»

## Стиль

По `START-HERE.md` в этой же папке.

## Тезис статьи

Главное узкое место современных систем — не вычислительная мощность, а движение данных между памятью и логикой. Архитектурное расстояние между HBM и вычислителем становится определяющим параметром производительности.

## Сцена

В центре кадра — большой 3D-куб тёмно-navy, разрезанный по вертикали почти точно пополам:
- **левая половина** куба — стек пластин памяти (имитация HBM): тонкие горизонтальные линии-светодиоды лиловыми;
- **правая половина** — сетка из аккуратных квадратов-вычислителей, каждый светится мягким фиолетовым.

Между двумя половинами — узкий **лаймовый канал** (зазор), по которому светящимися точками-импульсами движутся данные сверху вниз. Шесть-восемь маленьких точек на разных уровнях канала.

Сцена снимается слегка снизу, чтобы куб выглядел монументально.
