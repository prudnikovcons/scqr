# Обложка для статьи «Слой данных пришёл в обзоры. Это значит, что он перестал быть конкурентным преимуществом»

## Стиль (общий для всех обложек SCQR)

Photographic 3D-рендер с soft studio lighting и лёгким depth-of-field. Не плоский вектор, не stock, не collage. Сцена снимается как аналитическая инсталляция в студии.

Среда: лиловый фоновый градиент `#F1ECFF → #E9E2FF`, иногда тёплый край `#FFF8E8`. Лёгкая лиловая дымка для глубины.

Палитра объектов:
- Тёмно-navy `#17142E` — для тяжёлых элементов (серверы, плиты, корпуса)
- Фиолетовый `#7C5CFF` — акцентная подсветка, кнопки, точки
- Лайм `#A3E635` — ТОЛЬКО для сигнальных линий, стрелок, контрольных точек, не как фон
- Белый/слоновая кость — карточки, маскот
- Шрифт надписей на обложке: Inter / system-ui sans-serif

Композиция:
- Один сильный смысловой объект в центральных 60% по горизонтали (чтобы кроп до 4:3 в карточках архива не обрезал смысл)
- Заголовок и подзаголовок в верхнем-левом углу: тёмно-navy weight 700 + муть-лиловый weight 500
- Маленькое лого SCQR в правом верхнем углу (фиолетовый круг с одной лаймовой точкой, ~60×60 px area)
- Тонкая лаймовая горизонтальная линия по нижней кромке (5% высоты)

## Тезис статьи

Слой данных стал фундаментом для корпоративного ИИ. Конкуренция переехала наверх — на приложения, агенты, отчёты. Сам слой данных перестал быть конкурентным преимуществом и стал входным билетом, как в своё время СУБД, виртуализация, контейнеры.

## Сцена

Студийная композиция с тремя горизонтальными «этажами»:

1. **Внизу (~25% высоты)** — широкая массивная тёмно-navy серверная плита с матовым корпусом. На передней грани едва читается caps-надпись «СЛОЙ ДАННЫХ» тонким лиловым светом.

2. **Над плитой** — три белые стеклянные карточки в воздухе, парят на разной высоте. В каждой простая иконка (3D-объект):
   - линия графика,
   - чат-баблик,
   - шестерёнка.
   Карточки имеют тонкий фиолетовый стеклянный обод и лёгкое отражение от плиты ниже.

3. **Сверху** — от каждой карточки вверх уходит тонкий светящийся лаймовый луч. Три параллельных сигнала, уходящих за верхнюю кромку.

Идея: фундамент массивный, но взгляд уходит на лаймовые лучи — ценность накапливается выше слоя данных.
