# Обложка: «Отечественный ИИ-рынок между витриной и реальным спросом»

## Стиль семьи: `amber-indigo` (Архивный)

Палитра:
- Фон: тёплый кремовый `#FFF6E5 → #FCE9C8`
- Тяжёлое: deep indigo `#1F1A4E`
- Сигнал: янтарный `#F0B35A` — на сигнальных линиях и контрольных точках
- Доп. акцент: deep plum `#3D2A6B`
- Заголовок: `#1F1A4E`, подзаголовок: `#6B5A3D`
- Лого SCQR в правом верхнем углу (фиолетовый `#7C5CFF` с лаймовой точкой `#A3E635`).

3D-фоторендер по `START-HERE.md`. Soft studio lighting, depth-of-field. Архивный, бюрократический, документальный язык.

## Тезис статьи

Российский ИИ-рынок уже умеет красиво показывать себя — платформы, госстратегии, демонстрации, отчёты. Но между витриной и повторяемым спросом внутри реальных компаний лежит большой зазор: данные, кадры, экономика внедрения. Картина — два слоя, которые ещё не сошлись.

## Сцена

Архивная студия в кремово-янтарных тонах. В центре кадра **две параллельные горизонтальные платформы-плиты из тёмного indigo стекла**, стоящие одна над другой с зазором около трети высоты кадра.

**Верхняя плита — «витрина»**: на ней в ряд стоят три аккуратно оформленных индиго-кубика с янтарными контрольными точками-индикаторами на гранях. Один кубик чуть приподнят на тонком янтарном пьедестале — символ «парадного экспоната».

**Нижняя плита — «реальный спрос»**: на ней лежат разрозненные предметы — три-четыре небольших indigo-цилиндра разной высоты, неровно расставленные, без сигнальных индикаторов. Между ними виден тонкий слой пыли (мелкая фактурная текстура).

Между плитами — **видимый зазор**, через который проходит одиночный янтарный луч-стрелка снизу вверх (но не достигает верхней плиты, останавливается в воздухе на полпути). Это и есть разрыв.

В нижнем-правом углу композиции на фоне — едва различимый бумажный архивный лист с печатями (текстура, без читаемых надписей), намёк на бюрократическую среду.
