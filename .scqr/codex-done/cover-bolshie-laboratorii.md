## Тезис статьи

Покупатель фронтирной модели больше не платит «за модель». Он платит за режим доступа: SLA, mode of use, governance, audit-журналы, поддержка, обязательства. Сама модель — всего лишь ядро, вокруг которого выстроен сервис-контур.

## Сцена

Студийная композиция: в центре кадра парит **гладкий тёмно-navy шар** с лёгким фиолетовым свечением — это «модель». 

Вокруг шара по орбите — три прозрачных стеклянных кольца разной толщины, концентрических. На каждом кольце маленькие лаймовые контрольные точки-индикаторы. Каждое кольцо — это слой режима доступа: SLA, governance, audit.

Над шаром тонкая лаймовая стрелка указывает на одно из колец, а не на сам шар — главный смысл «теперь покупают это, а не центр».
