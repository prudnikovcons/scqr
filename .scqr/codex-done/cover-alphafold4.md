# Обложка: «AlphaFold 4: от структуры к поведению»

## Стиль

Полностью по `START-HERE.md` в этой же папке (3D-фотостудийный, лиловая среда, лайм только в сигнальных линиях, маскот в красных очках если присутствует).

## Тезис статьи

Главный смысл AlphaFold 4 — не точность модели сама по себе. Важнее то, что вычислительная биология подходит к вопросу «как белок ведёт себя», а не только «как он выглядит». Структура → поведение, статика → динамика.

## Сцена

В центре кадра — белая стеклянная карточка-3D с **спиралью белка**, плавно ротированной в перспективе. Спираль рендерится как лёгкая двойная лента, светится мягким фиолетовым внутри.

Над спиралью парят три маленьких контрольных точки на лаймовой пунктирной траектории — символ «теперь у нас есть динамика, поведение во времени». Точки в разных позициях, как будто три кадра одного движения.

По бокам — два меньших стеклянных кубика, на каждом тонкая лиловая надпись-плейсхолдер (без слов, просто пустые места под этикетку).

Подложка — лёгкое лиловое отражение, имитирующее полированный стол лаборатории.
