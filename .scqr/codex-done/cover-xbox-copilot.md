## Тезис статьи

5 мая Microsoft объявил: разработка Copilot для Xbox останавливается, мобильная версия сворачивается. Через год после показа на маркетинговых событиях. Параллельно — реорганизация Xbox-руководства с приходом четырёх execs из Microsoft CoreAI. Тезис: у крупных AI-вшивок есть срок годности — год-два. Если функция не нашла аудитории, её закрывают.

## Сцена

Студия в коралловых тонах. В центре кадра — **тёмно-navy блок-«контроллер»** (стилизованный куб с двумя выступами по бокам, очень упрощённый, без узнаваемых форм геймпада), **разделённый по диагонали тонкой коралловой линией**: верхняя половина блока остаётся целой, нижняя — превращается в **частицы-кубики**, которые рассыпаются вниз.

**Над блоком**, на уровне y≈350, парит **компактная коралловая стрелка** короткой формы (направлена вниз, к месту разлома) — символ, что отмена принятая, не случайная.

**В правой части кадра**, на уровне y≈500–650, видна **диаграмма команды** из 4–5 navy-силуэтов в ряд, с **одним коралловым силуэтом** в начале ряда — символ нового CEO с командой из CoreAI. Силуэты упрощённые, без лиц.

В нижнем левом плане кадра, едва различимо — **тонкая коралловая линия timeline** с двумя метками: одна слева (анонс), вторая справа (отмена) — отображает короткий жизненный цикл продукта без читаемых дат.
